# 小六壬三传解读框架（方法论）

> 本文档定义如何从三传卦象推导出有质量的解读。LLM 应严格按此框架步骤推理。

---

## 总览：七步推理法

任何一次解读都按以下顺序展开：

```
Step 1: 识别问题类别  →  确定 question_lens 索引
Step 2: 体用定位      →  锁定问者与所问事的力量对比
Step 3: 三传时序分析  →  逐传解读（带问题透镜）
Step 4: 五行整体流转  →  判断气运走势
Step 5: 特殊组合识别  →  叠加双符/三符格局含义
Step 6: 应期与方位    →  推断时间与空间指引
Step 7: 综合判断与建议 →  整合一切，给出可操作结论
```

每一步都对应 JSON 中的具体字段，下面逐一展开。

---

## Step 1：识别问题类别

### 8 类常见问题

| 类别 | 关键词 | JSON `question_lens` 索引 |
|---|---|:---:|
| 财运 | 钱、财、生意、投资、股票、加薪、奖金、买卖 | `财运` |
| 情感 | 恋爱、感情、婚姻、对象、复合、分手、表白 | `情感` |
| 事业 | 工作、项目、升迁、跳槽、offer、创业、面试 | `事业` |
| 健康 | 病、手术、康复、检查、体检、健康 | `健康` |
| 学业 | 考试、升学、留学、论文、面试（学术）、读书 | `学业` |
| 家庭 | 家人、父母、子女、配偶、家事、家宅 | `家庭` |
| 官非 | 官司、诉讼、纠纷、法律、合同争议 | `官非` |
| 出行 | 出差、旅行、搬家、远行、调动 | `出行` |

### 规则

1. **先识别后解读**：未识别问题类别就直接套基础吉凶，会与实际相差很远（如桃花对情感是 +2，对事业是 -1）。
2. **复合问题**：若用户问"换工作能否带来财运"，应同时考虑"事业"与"财运"两个透镜。
3. **若用户未提问题**：按"综合运势"处理，使用基础 `auspice_level`（不带透镜）。

### 怎么用 question_lens

每个符号在 JSON 中都有 `question_lens` 字段，例如：
```json
"大安": {"财运": 1, "情感": 2, "事业": 1, "出行": -1, ...}
```
解读时优先使用该类别下的值，而非 `auspice_level`。例如同样是大安，问情感是大吉，问出行却是小凶——这是大安"主静不主动"的体现。

## Step 2：体用定位

### 模型

- **初传 = 体** = 问者本身、起因、当前状态
- **末传 = 用** = 所问之事、最终结果、外境
- **中传 = 枢** = 过程枢纽、转折机制

### 体用五行关系含义

JSON 字段：`subject_object.relation`

| 关系 | 传统术语 | 现代解读 |
|:---:|---|---|
| 体生用 | "我去之" | 你主动投入此事，付出心力 — **散财耗力之兆** |
| 体克用 | "我克之" | 你掌控此事，主动权在己 — **主动有为之兆** |
| 用生体 | "他生我" | 此事反哺你，外力来助 — **受益来财之兆** |
| 用克体 | "他克我" | 此事压制你，外部压力大 — **受制受困之兆** |
| 体用比和 | "比和" | 你与事同气相求，平稳 — **和合稳定之兆** |

### 使用要点

- **体强用弱（体克用、用生体）** → 你能影响事态。
- **用强体弱（用克体、体生用）** → 事态影响你，被动多。
- **比和** → 稳但难有突破。

## Step 3：三传时序分析

### 时序角色

| 传 | 时段 | 含义 |
|:---:|:---:|---|
| 初传 | 前期 / 当前 | 事情起因、现状、问者本身状态 |
| 中传 | 中期 / 发展 | 过程演变、关键转折、外部介入 |
| 末传 | 后期 / 结果 | 最终归宿、事态收尾、长期影响 |

### 逐传解读模板

对每一传都回答三个问题：

1. **这个符号在此问题类别下意味着什么？**
   - 引用 `symbols_reference.md` 中该符号对应类别的解读。
2. **它和相邻传的五行关系如何？**
   - 引用 `relations` 字段的描述（生/克/被生/被克/同）。
3. **它的方位与神灵指向什么？**
   - 方位 → 空间趋避；神灵 → 可借力或避忌的能量。

### 优先级提示

- **末传最重要**（最终归宿）。
- **中传是关键**（决定能否到末传）。
- **初传是根基**（解释为什么从这里出发）。

## Step 4：五行整体流转

### 九种流转模式（JSON `flow.pattern`）

| 模式 | 模式特征 | 整体寓意 |
|:---|:---|---|
| **三同比和** | E1=E2=E3 | 力量集中稳固，走向单一，难突变 |
| **连珠相生** | E1→E2 生, E2→E3 生 | 气运绵延，事态自然推进，**最吉流转** |
| **连珠相克** | E1→E2 克, E2→E3 克 | 气运受制，层层阻碍，**最凶流转** |
| **首尾相应** | E1=E3, E2 不同 | 绕一圈回原点，过程曲折归宿明确 |
| **先比和后变化** | E1=E2, E3 不同 | 前期同气积蓄，末段发生转变 |
| **先变化后比和** | E2=E3, E1 不同 | 前期发力，末段归稳 |
| **始生终克** | E1→E2 生, E2→E3 克 | 开局顺利末段受阻，将成而遇阻 |
| **始克终生** | E1→E2 克, E2→E3 生 | 开局艰难末段转顺，**先苦后甜** |
| **生克交杂** | 其他 | 起伏多变，无定向规律 |

### 应用规则

- **连珠相生 + 末传吉** = 上上之卦（运势顺遂到底）
- **连珠相克 + 末传凶** = 下下之卦（步步受困）
- **始克终生** + 趋势"苦尽甘来" = 短期看坏，长期看好
- **始生终克** + 趋势"盛极而衰" = 短期看好，长期需防

## Step 5：特殊组合识别

JSON 字段：`combinations`

### 优先级

1. **三符格局**（罕见但权重最重）：如"三安格""三口格""三空格"等，直接定调。
2. **双符组合**：补充修饰，叠加吉凶。

### 应用方式

- 若 `combinations` 列表为空：仅按基础三传分析。
- 若有 1-2 个双符组合：将其含义融入对应阶段的解读（例如"留连+赤口=缠斗反复"出现在初中传则强调过程纠葛）。
- 若有三符格局：以三符格局含义为主线，其他元素辅助。

### 高频组合的解读重点

- **吉性组合**（valence "+"）→ 强化吉象、降低凶象冲击。
- **凶性组合**（valence "-"）→ 警示具体凶险方向，给出化解建议。
- **中性/转化组合**（valence "0"）→ 提示"可吉可凶取决于行动"。

详细组合谱见 [combinations_reference.md](combinations_reference.md)。

## Step 6：应期与方位指引

### 应期推断（基于末传五行）

JSON 字段：`timing_guidance`

| 末传五行 | 季节 | 月份（农历） | 时辰 | 颜色 |
|:---:|:---:|---|---|---|
| 木 | 春 | 正月、二月 | 寅(03-05)、卯(05-07) | 青、绿 |
| 火 | 夏 | 四月、五月 | 巳(09-11)、午(11-13) | 红、紫 |
| 土 | 四季月 | 三、六、九、十二月 | 辰、未、戌、丑 | 黄、棕 |
| 金 | 秋 | 七月、八月 | 申(15-17)、酉(17-19) | 白、银 |
| 水 | 冬 | 十、十一月 | 亥(21-23)、子(23-01) | 黑、深蓝 |

### 方位指引

- **吉方** = 三传中吉性符号的方位（`favorable_directions_from_passes`）→ 朝此方位行事
- **避方** = 三传中凶性符号的方位（`avoid_directions_from_passes`）→ 避免此方位
- **末传五行方位** = 应期之地（`element_directions`）

### 神灵借力

- **吉性符号的神灵**（`favorable_deities`）可"心存敬意，借其能量"。
- 例：见天德则可"求贵人""向西北方求事"。

## Step 7：综合判断与建议

### 输出结构

最终给用户的解读应包含：

1. **卦象总览**（一句话定调）：
   - 引用整体格局、五行流转、趋势
   - 例："二吉一凶（中上格），连珠相生，渐入佳境之卦"

2. **时间脉络**（初/中/末三传）：
   - 每传 2-3 句，带问题透镜的具体含义
   - 突出末传

3. **核心动力**（体用 + 五行流转）：
   - 解释"为什么会这样发展"

4. **关键提示**（特殊组合）：
   - 若有 1-3 个突出组合则点出，给出对应建议

5. **行动建议**（应期 + 方位 + 神灵）：
   - 何时（季节/月份/时辰）
   - 何地（方位）
   - 借助什么力量（贵人/神灵）

6. **结论**（回到问题本身）：
   - 直接回答用户的问题（能成 / 不能成 / 部分成 / 需要某条件）

### 风格指南

- 优雅、富有哲理的中文，但保持易懂。
- 避免极端断言（"必然如何"），用"宜""忌""可""需"等留余地。
- 与具体问题强绑定，避免泛泛而谈。
- 控制在 600-1000 字（中文）。

## 反例：常见错误解读

### ❌ 错误：脱离问题套基础吉凶
"末传是大安，所以是吉。"
**改正**：问出行时，大安主静反而 -1 不吉，应说"末传虽为大安大吉，但其主静的属性对出行而言意味着行程拖延、不顺"。

### ❌ 错误：只看符号不看五行流转
"初传速喜，中传赤口，末传大安。整体不错。"
**改正**：应说"虽末传大安落于吉位，但中传赤口对末传形成被克之势（金克木），暗示稳定到来前会经历明显冲突，需做好心理准备"。

### ❌ 错误：忽略特殊组合
"三传分别是空亡、赤口、桃花..."
**改正**：应识别出"刑耗交加""赤口桃花情斗"等组合，把组合含义融入解读，而非仅孤立看符号。

### ❌ 错误：不给应期方位
仅说"整体吉/凶"。
**改正**：必须给出具体的时间窗口（如"申酉月"或"15-19 时"）和方位（如"宜西方求财"）。
