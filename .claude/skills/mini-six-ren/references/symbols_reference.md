# 小六壬九宫符号详解

> 本文件是 LLM 解读三传时的核心知识库。每个符号包含：基础属性、传统含义、按问题类型分化的吉凶倾向、神灵能量场。

## 一、九宫掌诀排列

```
食指尖:   [留连②]
食指根:   [大安①] ← 起点（顺时针推 1-9 步循环）
中指根:                [速喜③]
                         ↓
无名指根: [天德⑨]    [赤口④]
                         ↓
无名指尖:               [小吉⑤]
中宫:     [空亡⑥]
中宫旁:   [病符⑦]  [桃花⑧]
```

**循环顺序**：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡 → 病符 → 桃花 → 天德 → 回到大安

## 三、每个符号详解（按问题类型分化）

### 1. 大安（木 · +2 大吉 · 正东 · 三清）

**核心意象**：万物归根，安然不动；静中藏机，稳如山岳。

**传统断语**：
- 求事缓慢成，求人见迟疑。
- 财在艮方位，宅舍保安康。
- 行人身未动，病者主无妨。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | +1 吉 | 长期稳定增长，但难有暴利；适合储蓄、定投 |
| 情感 | +2 大吉 | 感情归于稳定；恋爱步入正轨，已婚相敬如宾 |
| 事业 | +1 吉 | 工作稳定但晋升慢；不宜跳槽换岗 |
| 健康 | +2 大吉 | 身体康健；病者将愈 |
| 学业 | +1 吉 | 厚积薄发；适合长期主修而非应急 |
| 家庭 | +2 大吉 | 阖家平安、家宅康宁 |
| 官非 | +2 大吉 | 官司可缓可解；事态平息 |
| 出行 | -1 凶 | 大安主静，行动不顺；行程拖延 |

**神灵能量**：三清（道教最高三神）— 主清静无为，宜守持本心。

---

### 2. 留连（木 · 0 中性 · 东南 · 文昌）

**核心意象**：藕断丝连，进退两难；事有牵绊，难以了断。

**传统断语**：
- 留连事难成，求物在他乡。
- 走失未远去，宜向东南方。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | -1 凶 | 财物难收回；借贷不归 |
| 情感 | +1 吉 | 旧情未了；想挽留则是吉，想分则是凶 |
| 事业 | -1 凶 | 项目拖延；审批卡壳 |
| 健康 | -1 凶 | 病程拖延、反复不愈 |
| 学业 | 0 中 | 进度迟缓但未中断；需耐心 |
| 家庭 | 0 中 | 家庭关系藕断丝连；纠葛缠绕 |
| 官非 | 0 中 | 官司久拖不决 |
| 出行 | -1 凶 | 路途多阻、行程延误 |

**神灵能量**：文昌（文运之神）— 主文事缠绵，宜耐心打磨。

---

### 3. 速喜（火 · +2 大吉 · 正南 · 雷祖）

**核心意象**：喜从天降，雷霆万钧；快速突然，吉来如电。

**传统断语**：
- 速喜喜来临，求财向南行。
- 失物申未午（时辰）见，行人路上身。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | +2 大吉 | 速财、横财；投资短期见效 |
| 情感 | +2 大吉 | 速配速合；告白、求婚易成 |
| 事业 | +2 大吉 | 升迁突至；offer 速到 |
| 健康 | -1 凶 | 喜→突发；可能突发病症（高血压、心脑） |
| 学业 | +1 吉 | 考运临头；急中生智 |
| 家庭 | +1 吉 | 家中有喜事 |
| 官非 | +1 吉 | 官司速判；速战速决 |
| 出行 | +2 大吉 | 出行顺利、归来如风 |

**神灵能量**：雷祖（雷部主神）— 主迅猛果决，宜把握刹那。

---

### 4. 赤口（金 · -2 大凶 · 正西 · 将帅）

**核心意象**：金戈铁马，刀剑相向；口舌肉身，皆主刑伤。

**传统断语**：
- 赤口主口舌，凡事都不吉。
- 行人有惊险，疾病主神灵。
- 失物急寻取，宜向西方寻。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | -2 大凶 | 破财、被骗、被讨债 |
| 情感 | -2 大凶 | 口角争吵、感情破裂 |
| 事业 | -2 大凶 | 同事冲突、被批评、被开除 |
| 健康 | -2 大凶 | 外伤、手术、意外受伤 |
| 学业 | -1 凶 | 与师同学冲突；考运不佳 |
| 家庭 | -2 大凶 | 家人争吵；亲情失和 |
| 官非 | -2 大凶 | 官司必败；牢狱之灾 |
| 出行 | -2 大凶 | 路途凶险；交通事故 |

**神灵能量**：将帅（征战之神）— 主刑伤口舌，宜避其锋。
**化解**：见赤口可借天德（贵人调停）、大安（以静制动）。

---

### 5. 小吉（水 · +1 小吉 · 正北 · 真武）

**核心意象**：小溪潺潺，涓流入海；初见成效，尚需积累。

**传统断语**：
- 小吉最吉昌，财物在坤方。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | +1 吉 | 小有进账；不大但稳 |
| 情感 | 0 中 | 感情初萌；进展缓慢 |
| 事业 | +1 吉 | 小有突破；项目初见雏形 |
| 健康 | 0 中 | 小恙无碍；勿轻视 |
| 学业 | +1 吉 | 小有进步；适合起步阶段 |
| 家庭 | 0 中 | 家事平平 |
| 官非 | 0 中 | 官司有转机但未结 |
| 出行 | 0 中 | 行程顺但路途短 |

**神灵能量**：真武（北方水神）— 主水气积蓄，宜从小处入手。

### 6. 空亡（土 · -2 大凶 · 中宫 · 玉皇）

**核心意象**：空中楼阁，镜花水月；现实落空，虚境反成。

**传统断语**：
- 空亡事不祥，阴人多乖张。
- 财物多耗散，宅舍要提防。

**按问题分化**：
| 问题 | 倾向 | 解读 |
|:---:|:---:|---|
| 财运 | -2 大凶 | 财空、被骗、投资归零（**最忌**） |
| 情感 | -1 凶 | 情缘虚幻；遇渣男渣女 |
| 事业 | -2 大凶 | 工作落空、offer 撤销 |
| 健康 | -1 凶 | 病情虚浮难诊；可能无中生有 |
| 学业 | -1 凶 | 学业荒废；考试落榜 |
| 家庭 | -1 凶 | 家人离散 |
| 官非 | -1 凶 | 官司悬而未决 |
| 出行 | -2 大凶 | 行程取消；途中折返 |

**特殊**：
- 求**虚幻之事**（修行、艺术、构思、玄学）反而吉 — 空中得真。
- 求**实际之事**（金钱、健康、合同）则大忌。

**神灵能量**：玉皇（中央至尊）— 主天威无形，宜放空求空。

## 四、五行生克与解读规则

### 五行循环

```
相生 (顺势)：木 → 火 → 土 → 金 → 水 → 木
相克 (逆势)：木 → 土 → 水 → 火 → 金 → 木
```

### 六种关系

| 关系 | 含义 | 对事态影响 |
|:---:|---|---|
| **生** | E1 生 E2 | 顺势推进、自然演化 |
| **克** | E1 克 E2 | 形成压制、需克服阻碍 |
| **被生** | E2 生 E1 | 得到反哺、外力扶助 |
| **被克** | E2 克 E1 | 受到压制、形势不利 |
| **同** | E1 == E2 | 比和加力、稳固难变 |
| 无 | 无直接关系 | 罕见，五行中实际全相关 |

### 关系应用：体用判断

**初传 = 体（问者）**，**末传 = 用（所问事）**：

- **体生用**：散财耗力 — 你给事付出，事虽可成需消耗。
- **体克用**：主动有为 — 你掌控事，吉象。
- **用生体**：来财来缘 — 事反哺你，受益。
- **用克体**：受制受困 — 事压你，凶象。
- **体用比和**：和合稳定 — 同气相求，缺变数。

## 五、解读优先级

1. **末传为主**（最终归宿）。
2. **五行整体流转**（连珠相生 / 连珠相克 / 比和 / 交杂）。
3. **体用关系**（你与事的力量对比）。
4. **特殊组合**（双符 / 三符特殊格局）。
5. **吉凶等级与问题透镜**（按 question_lens 分化判断）。
6. **应期方位**（基于末传五行 + 三传方位汇总）。
7. **神灵能量**（借力或避忌）。

## 六、吉凶简判（速查）

- **三大吉**：大安、速喜、天德
