# 小六壬特殊符号组合谱

> 当三传中出现特定的符号组合时，会形成传统术数中的"格"或"组合"。算法层会自动识别并在 JSON 的 `combinations` 字段中标注。本文档提供详解。

---

## 一、组合识别规则

### 双符组合（COMBINATIONS_2）

只要三传中**任意两传**出现指定的符号对，即视为该组合成立。同一组合若多对出现，仅记一次。

### 三符格局（TRIPLE_PATTERNS）

仅当三传的**符号完全相同**（如三个大安、三个赤口）时成立。三符格局优先于双符组合。

### 顺序无关性

组合识别**不考虑顺序**。例如：
- 大安+天德 = 安德相辅（无论谁在初传/末传）
- 赤口+空亡 = 刑耗交加（无论先后）

---

## 二、双符组合详解

### 大吉组合（valence: +）

#### 安德相辅（大安 + 天德）
- **属性**：木 + 金（金克木，但因都为大吉，反成"贵人扶安"）
- **含义**：贵人扶持稳定，事有靠山可依。
- **应用**：求事必成、求人必应；婚姻、事业、家庭最佳。
- **化用**：若一传是大安一传是天德，事态"稳中得贵"。

#### 安喜相会（大安 + 速喜）
- **属性**：木 + 火（木生火）
- **含义**：稳中有喜，渐进有成。
- **应用**：好事将至但不喧嚣；适合长期规划中的喜事（婚事、迁居、升迁）。

#### 喜从天降（速喜 + 天德）
- **属性**：火 + 金（火克金，但同为大吉，化为"贵人带喜"）
- **含义**：贵人带喜，事来如风。
- **应用**：意外之喜与贵人相关；offer、表白、合同签订等。

#### 渐入安境（大安 + 小吉）
- **属性**：木 + 水（水生木）
- **含义**：由小成至大稳，循序渐进。
- **应用**：起步事业、初恋成稳、初步治疗见效。

#### 小成速达（小吉 + 速喜）
- **属性**：水 + 火（水克火，但同为吉，化为"小成速达"）
- **含义**：起步顺遂，喜事相承。
- **应用**：开始就有突破，接连有喜。

#### 贵人小成（小吉 + 天德）
- **属性**：水 + 金（金生水）
- **含义**：贵人扶持，渐积小成。
- **应用**：长辈提携下慢慢积累。

#### 喜花相会（速喜 + 桃花）
- **属性**：火 + 土（火生土）
- **含义**：情缘速至，异性带来喜事。
- **应用**：恋爱速配；情场得意；异性贵人带来财运。

#### 情归稳定（大安 + 桃花）
- **属性**：木 + 土（木克土，因大安主稳，化为"情趋稳定"）
- **含义**：情感趋稳，宜定不宜变。
- **应用**：恋情转入婚姻；夫妻关系修复。

#### 贵人医治（天德 + 病符）
- **属性**：金 + 土（土生金）
- **含义**：病灾有解，难处有人援助。
- **应用**：求医得名医；困境得贵人。

#### 困中遇援（留连 + 天德）
- **属性**：木 + 金（金克木，但天德解留连之困）
- **含义**：纠缠困境中得贵人解围。
- **应用**：拖延的项目得高层推动；久拖官司有调停。

#### 缠中得喜（留连 + 速喜）
- **属性**：木 + 火（木生火）
- **含义**：反复纠缠中迎来转机。
- **应用**：久攻不下的事忽然柳暗花明。

### 凶组合（valence: -）

#### 刑耗交加（赤口 + 空亡）
- **属性**：金 + 土（土生金，**最凶组合之一**）
- **含义**：争斗中破财损物，亦可破而后立。
- **应用**：诉讼破财；冲突造成损失；亦可看作"旧业不破新业不立"。

#### 静中起波（大安 + 赤口）
- **属性**：木 + 金（金克木）
- **含义**：稳定中突遇冲突，需防意外争端。
- **应用**：平静日常中突发口角、平稳工作中遭排挤。

#### 安转空寂（大安 + 空亡）
- **属性**：木 + 土（木克土，但空亡化大安之稳为空）
- **含义**：看似稳实则空，需警惕表象。
- **应用**：表面平稳实际暗藏空洞；情感淡如止水。

#### 喜事虚浮（速喜 + 空亡）
- **属性**：火 + 土（火生土，但空亡化喜为虚）
- **含义**：喜来如风去亦如风，难以持久。
- **应用**：offer 撤回；订婚后悔婚；昙花一现的好消息。

#### 缠斗反复（留连 + 赤口）
- **属性**：木 + 金（金克木）
- **含义**：纠缠不清，争执反复。
- **应用**：分手反复；持久战争论；离婚拉锯。

#### 病滞难解（留连 + 病符）
- **属性**：木 + 土（木克土）
- **含义**：病灾纠缠，过程漫长。
- **应用**：慢性病；久治不愈；心病难医。

#### 缠空相侵（留连 + 空亡）
- **属性**：木 + 土
- **含义**：反复折腾终归虚无。
- **应用**：长期投入打水漂；漫长努力终成空。

#### 病虚两亡（病符 + 空亡）
- **属性**：土 + 土（比和但都凶）
- **含义**：病情虚浮难定，求医如缘木。
- **应用**：莫名的不适，查无实病；心因性疾病。

#### 贵援落空（天德 + 空亡）
- **属性**：金 + 土
- **含义**：求贵无门，外援空缺。
- **应用**：找人帮忙无果；推荐信落空；贵人爽约。

#### 斗中受伤（赤口 + 病符）
- **属性**：金 + 土（土生金）
- **含义**：争斗中身心受损，病由争起。
- **应用**：因争吵导致身心疾病；冲突致伤。

#### 小成转空（小吉 + 空亡）
- **属性**：水 + 土（土克水）
- **含义**：初有小成终归虚无。
- **应用**：起步阶段顺利但后期落空。

#### 小成受阻（小吉 + 赤口）
- **属性**：水 + 金（金生水，但赤口冲小吉）
- **含义**：初有小成被冲突打断。
- **应用**：刚起步遇阻；初恋遇阻。

#### 喜中带病（速喜 + 病符）
- **属性**：火 + 土（火生土）
- **含义**：喜事中夹病灾，乐极生悲之兆。
- **应用**：婚礼前生病；升迁后健康受损；过度兴奋伤身。

#### 情斗纠葛（赤口 + 桃花）
- **属性**：金 + 土（土生金）
- **含义**：情感纷争，异性口舌之祸。
- **应用**：恋人/夫妻争吵；桃色官司；异性纠葛。

#### 情空花谢（空亡 + 桃花）
- **属性**：土 + 土
- **含义**：情缘虚幻，桃花落空。
- **应用**：表白被拒；恋情幻灭；遇骗婚。

#### 情伤病扰（病符 + 桃花）
- **属性**：土 + 土
- **含义**：情感纠葛带来病忧或心伤。
- **应用**：相思成疾；情感引发抑郁。

### 中性 / 转化组合（valence: 0）

#### 贵人解争（天德 + 赤口）
- **含义**：争斗中有调停者，凶象可化解。
- **应用**：官司中得调解；冲突中第三方介入。
- **使用**：可吉可凶取决于是否求助贵人。

#### 安抚病情（大安 + 病符）
- **含义**：病势趋稳但需长期调养。
- **应用**：慢性病稳定期；亚健康状态。

#### 情缠不解（留连 + 桃花）
- **含义**：感情牵绊难断，纠葛持续。
- **应用**：分不开也好不到一起；老情人纠缠。
- **使用**：想留则吉、想断则凶。

#### 虚中得援（空亡 + 天德）
- **含义**：看似无望中现贵人转机。
- **应用**：山穷水尽柳暗花明。

## 三、三符格局详解

三符格局是三传完全相同时形成的特殊卦象，极为罕见但分量最重。

### 三安格（三个大安）
- **判定**：极静停滞，山如止水。
- **吉象**：求安稳事（婚姻稳定、家宅平安、健康长寿）→ 大吉。
- **凶象**：求变动事（跳槽、出行、突破）→ 大凶，需主动破局。
- **建议**：审时度势——是该稳还是该变？三安格逼问真实意图。

### 三喜格（三个速喜）
- **判定**：喜悦连绵或虚惊重重。
- **吉象**：求短期突破、求快速结果 → 极吉。
- **凶象**：求长期稳固之事 → 来得快去得快，难以持续。
- **特殊**：火气过旺，注意心血管、情绪过激。

### 三口格（三个赤口）
- **判定**：争端激化至极，或反凶为吉。
- **吉象**：求斗争性事（诉讼对抗、竞技比拼）可能反转。
- **凶象**：求和谐事 → 极凶。
- **建议**：避其锋而退守；或反借其势主动出击（破局）。

### 三空格（三个空亡）
- **判定**：极虚之象。
- **吉象**：虚幻之事（修行、艺术、玄学、构思、写作）→ 反成。
- **凶象**：现实之事（金钱、健康、合同）→ 大忌，皆主"无"。
- **建议**：把握"空"的两面性——放下实，专注虚。

### 三德格（三个天德）
- **判定**：贵人云集，事必有助。
- **吉象**：求贵人事 → 极吉。
- **警示**：过度依赖外力，自身根基弱时仍不稳。
- **建议**：抓住贵人但勿懒惰，求人不如自助。

### 三连格（三个留连）
- **判定**：极度缠绕，进退两难。
- **吉象**：求挽留事（破镜重圆、续约） → 可能成。
- **凶象**：求快速了断 → 极难。
- **建议**：斩断牵绊方能前进。

### 三病格（三个病符）
- **判定**：病难深重，需长期调理。
- **凶象**：健康类问题 → 极凶。
- **警示**：积劳积患，需立即休养。
- **建议**：寻医（结合天德更佳，但三病格本身无天德）。

### 三桃格（三个桃花）
- **判定**：情缘极盛或情劫深重。
- **吉象**：求恋情、求合婚 → 极吉。
- **凶象**：已婚求事业、求清静 → 大凶，桃花劫。
- **特殊**：人际网络异常活跃，但分散精力。

### 三小吉格（三个小吉）
- **判定**：积小成大，循序渐进。
- **吉象**：长期积累、稳健投资 → 吉。
- **警示**：不宜冒进，无大喜大悲。
- **建议**：稳扎稳打，每天进步一点。

## 四、组合应用优先级

当 JSON 的 `combinations` 字段返回多个组合时，按以下优先级整合到解读中：

1. **三符格局**（若存在）→ 作为整卦定调，其他元素辅助。
2. **凶性组合**（valence: "-"）→ 重点警示，给出化解建议。
3. **吉性组合**（valence: "+"）→ 强化吉象，明确利好方向。
4. **中性/转化组合**（valence: "0"）→ 提示"取决于行动"，引导用户做出选择。

### 一卦最多组合数

理论上三传符号若全不同，最多产生 3 个双符组合（三两组合的所有 pair）。实际罕见同时有 3 个有意义的组合。若超过 2 个，挑最关键的 2 个详细解读，其余一笔带过。

---

## 五、缺失组合的处理

若 `combinations` 字段为空，表示三传中没有形成传统组合。此时：
- 不强行编造组合。
- 回归基础三传 + 五行流转分析。
- 强调 `subject_object` 体用关系作为主线。
